Simplanner
Simple Planner for Students
Team Name: Simplanner Team
Project Name: Simplanner

1.Project Description
Simplanner is a simple web application designed to help students organize their daily tasks, study schedules, and deadlines.

The main goal of the project is to provide an easy-to-use tool for managing tasks and improving time management.

2.Target Users
Our application is designed primarily for university students who want to organize their academic responsibilities.

3.Main Features
The application will allow users to:

Add new tasks.
Set deadlines for tasks.
View a list of planned tasks.
Mark tasks as completed.
Delete tasks.


4.Main User Process
The user opens the Simplanner website.
The user enters a new task.
The user selects a deadline.
The user clicks the "Add Task" button.
The task appears on the task list.
The user marks the task as completed when finished.

5.Technologies
We plan to use the following technologies:

HTML – Website structure.
CSS – Visual design.
JavaScript – Application functionality.
LocalStorage – Saving tasks in the browser.
GitHub – Version control and task management.
Discord – Team communication.
